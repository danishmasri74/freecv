# Fonts

These fonts ship with FreeCV, subset to Latin, as variable WOFF2 files from [Fontsource](https://fontsource.org).
All are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and redistribution.

| File | Family | Used by | Copyright holder |
| --- | --- | --- | --- |
| `source-sans-3.woff2` | Source Sans 3 | Harbor | Adobe |
| `source-serif-4.woff2`, `source-serif-4-italic.woff2` | Source Serif 4 | Ledger | Adobe |
| `manrope.woff2` | Manrope | Atlas | The Manrope Project Authors |
| `ibm-plex-sans.woff2` | IBM Plex Sans | Quiet | IBM Corp. |

A browser only downloads the font for the template that's in use.
