    Save as PDF

    Your browser's print window will open. To get a clean PDF:

    1. Set Destination to Save as PDF.
    2. Under More settings, turn off “Headers and footers”.
    3. Keep Margins on Default and Scale at 100%.

    The text stays selectable, so applicant tracking systems (ATS) can read it.

    About FreeCV

    Lots of “free” resume builders charge you at the download step. FreeCV doesn't, and never will.

    • No account, no sign-up, no tracking.
    • Your resume lives only in this browser. Nothing is uploaded.
    • Use Export to save a backup file and Import to load it on another device or browser.
    • PDFs come from your browser's print feature, so the text stays real text that ATS software can read.
